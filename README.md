# AegisGuard-UEBA
AegisGuard — An AI-powered User and Entity Behavior Analytics (UEBA) platform that detects insider threats and data exfiltration.
- What it does: Identifies behavioral drift and anomalous user activity in real-time, instantly triggering an automated "Kill Switch" to isolate compromised sessions.
- Tech Stack: Python, Isolation Forest (Scikit-Learn), DistilBERT (Hugging Face), FastAPI, Streamlit, Supabase (PostgreSQL), and Docker.
